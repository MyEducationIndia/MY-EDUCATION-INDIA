# MY EDUCATION INDIA ERP V2 — FRONTEND PRESENTATION LAYER

## Overview
Built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS**. Provides responsive portals across 10 institutional roles (Root Owner, Super Admin, Institute Admin, Branch Admin, Faculty, Student, Counsellor, Accountant, Receptionist, Developer) and dynamic visual builders.

## Compliance
- **Zero Client-Side Storage**: 100% compliant with enterprise security standards: zero usage of `localStorage`, `sessionStorage`, or `indexedDB`.
- **Edge Deployment**: Pre-configured for zero-error SPA deployment on Vercel via `vercel.json`.

## Local Execution
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
